# Cesium 园区 GIS

入口：`http://127.0.0.1:5186/#gis`，顶部“GIS 园区”。与园区总览、3DGS 共用本项目端口，不依赖其他本地服务。

Cesium 1.145.0 及运行资源在 `public/gis/cesium`，模型从现有 OBJ 导出为 8 栋楼和场地共 9 个 GLB。复用 `campusMaterials.ts` 深色金属、青色玻璃及科技蓝屋顶材质。省略外围示意楼块，保留模型场地、内部道路和绿化。选择楼栋可以进入原有楼栋分析页面。

## 地址与精度

用户指定地址：广州市黄埔区笔村大路78号。

- 黄埔区政府公示确认该地址为广新·黄埔新质产业园，且总平面图与园区模型布局基本一致：https://www.hp.gov.cn/zwgk/gsgb/pqgs/content/post_10330094.html
- 2026-10-02 在百度地图搜索完整地址，结果“笔村大路78号”列出同名园区；园区分享链接：https://j.map.baidu.com/70/n3BM
- 地址搜索自动定位的地图中心 BD09MC 为 `[12639390.125, 2628995]`，用 gcoord 1.0.7 转为 WGS84 `[113.52869054948646, 23.111421045580343]`。这是地址搜索视窗的中心，**不是测绘点，也不保证是园区几何中心**。
- 初始化锚点取 `[113.528691, 23.111421]`。初始朝向 10° 参考公示图大致方向；模型按原始单位暂按米使用（比例 1），没有沿用 Three 展示缩放 0.32。朝向、尺寸、地块边界均未实测，页面明确标注“地址级定位 · 朝向与尺寸待校准”。
- “位置校准”允许调整 WGS84 经度、纬度、朝向、高程和统一比例，保存到本机 localStorage。生产精确落位需要测绘控制点/地块红线坐标，不能用本预览替代。

## 地图与坐标

底图使用 Esri World Imagery 卫星影像（server.arcgisonline.com，Web Mercator / WGS84），在浏览器逐瓦片转成深蓝配色，模型材质不受底图处理影响。保留版权与浏览器 HTTP 缓存，不预抓取或离线下载。当前是椭球地表，不包含实测地形高程。大型生产部署应配置适合业务流量的底图服务。

模型以本地 ENU 切平面定位；原 OBJ 为 Y-up，Cesium 加载使用 `upAxis:Y, forwardAxis:X`，保证转换为 ENU 的 `[x,-z,y]`，楼栋标签使用相同变换。矩阵中的锚点为 WGS84，经纬度不可直接填入高德 GCJ02 或百度 BD09 坐标。

## 构建

修改模型/材质后执行 `npm run build:gis`，复制本地 Cesium runtime 并重新导出 GLB；编辑页面可直接修改 `public/gis`。最终执行 `npm run build` 会复制全部 GIS 资源至 dist。模型解析在本地完成，无需上传到 Cesium ion，也不需要 ion token。
